# Sentinel-10x10 — SIGMAR

Automatización gratuita de imágenes Sentinel-2 L2A para las Ciénegas del Lerma.

Estado: preparación inicial. Se requiere configurar un polígono real antes de ejecutar la descarga. Se procesarán las bandas B02, B03, B04, B08, B11 y B12. La publicación en SIGMAR todavía no está integrada.

Objetivo: buscar escenas de baja nubosidad, generar GeoTIFF multibanda, imagen RGB y metadatos; ejecutar mensualmente con GitHub Actions sin servicios de pago.
